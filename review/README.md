# রিভিউ পেইজ (অস্থায়ী)

PR #11 মার্জের আগে পরিবর্তন দেখার জন্য — চোখে দেখার মতো আগে/পরে তুলনা।

- `compare.html` — দুটো পেইজ পাশাপাশি, পার্থক্য দাগানো
- `before-login.html` — main-এর লগইন পেইজ (তিনটি স্টাফ লিংকসহ)
- `after-login.html` — PR #11-এর লগইন পেইজ (লিংক ছাড়া)

তুলনায় যা ব্যবহৃত:
- `before-login.html` = `main` (`aa50274`) এর `index.html` থেকে নেওয়া `#authScreen` অংশ
- `after-login.html` = এই ব্রাঞ্চের `index.html` থেকে নেওয়া একই অংশ
- দুই ফাইলেই আসল `styles.css`/`css/*.css` + আইকন স্প্রিট, শুধু `<script>` বাদ

রিভিউ শেষে এই ফোল্ডারটি মুছে ফেলা হবে, যাতে মার্জে অপ্রয়োজনীয় ফাইল না যায়।
