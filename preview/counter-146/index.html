শুধু আজকের লেনদেন ও সহজ পেমেন্ট

নাম, Student ID বা ইউনিক রোল দিয়ে সার্চ → ন্যূনতম পরিচয় → পেমেন্ট। বকেয়া তালিকা, বিস্তারিত শিক্ষার্থী প্রোফাইল বা বাড়তি কাউন্টার পেইজ নেই।

রসিদে R + সাল + মাস + দিন + তিন অঙ্কের ক্রমিক। বাড়তি suffix নেই। সাদাকালো PDF অফলাইনে তৈরি হয়। নমুনা PDF।

এগুলো আসল অ্যাপের পরীক্ষামূলক অ্যাকাউন্টের স্ক্রিনশট। কোনো বাস্তব শিক্ষার্থী বা লেনদেন নয়। স্ক্রিনে থাকা Sync Failed বার্তা লুকানো হয়নি; এই কাজ backend বা লাইভ deployment পরিবর্তন করেনি। শেয়ারড স্টোরেজ/ক্লাউডে পূর্ণ সার্ভার-স্তরের তথ্য বিচ্ছিন্নতা নিশ্চিত করা হয়নি।
